# Clinical Lab Results Analyzer

A full-stack application that analyzes clinical laboratory test results, classifies them, routes them based on severity, and provides an LLM-generated explanation using the Kaggle Anonymized Laboratory Test Results dataset.

## Architecture

- **Backend:** FastAPI (Python)
- **Frontend:** React (Vite)
- **Agent Logic:** Classify -> Route -> Explain
- **LLM Integration:** Analyzes every result, including normal ones
- **MCP Server:** Provides reference range fallback for unknown tests
